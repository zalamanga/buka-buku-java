# Asal proyek

Versi ini melanjutkan `BukaBuku1Project`, aplikasi JSF/Hibernate yang sebelumnya memakai NetBeans/Ant dan library dari lokasi komputer pengembang.

- Halaman akun asal mencantumkan `Copyright © 2023 BukaBuku`.
- DAO dan helper Hibernate asal memiliki penanda penulis `SEAN`. Atribusi tersebut dipertahankan di catatan ini setelah pemisahan model, penyimpanan, autentikasi, dan view.
- Logo, ilustrasi buku, dan sembilan gambar sampul berasal dari proyek asal. Tidak ada lisensi aset tambahan yang diberikan oleh pembaruan ini; hak gambar dan buku tetap pada pemegang hak masing-masing.
- Metadata awal mengikuti katalog contoh pada proyek asal. Tanggal dan judul dipakai sebagai data demonstrasi, bukan katalog penerbit yang diverifikasi.
- JSF, Hibernate, MySQL Connector/J dan dependency lain memiliki lisensi masing-masing pada distribusi mereka.

Sumber lama tetap dicadangkan terpisah. Repository ini tidak memuat database pengguna, konfigurasi lokal, hasil build lama, atau test lama yang menulis ke database asal.
