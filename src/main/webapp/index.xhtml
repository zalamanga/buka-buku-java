Tentang BukaBuku

Proyek belajar Java untuk menampilkan dan mengelola metadata buku. Katalog dapat dibaca tanpa akun; pengguna terdaftar berbagi koleksi demo yang sama.

Aplikasi ini tidak menjual buku atau menyediakan isi buku digital. Gambar sampul tetap menjadi milik pemegang hak masing-masing.
